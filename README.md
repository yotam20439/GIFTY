# כרטיסים — ארנק כרטיסי המתנה

אפליקציית Next.js בעברית שמרכזת את כרטיסי המתנה: כמה יש, כמה נשאר בכל אחד, מתי כל אחד פג, ומספר הכרטיס נגיש בלחיצה כשעומדים בקופה.

## הרצה מקומית

```bash
npm install
npm run dev
```

## העלאה ל-Vercel

```bash
npm i -g vercel
vercel        # תצוגה מקדימה
vercel --prod # פרודקשן
```

או: דוחפים ל-GitHub, ב-Vercel לוחצים **Add New → Project**, בוחרים את הריפו, **Deploy**. אין משתני סביבה להגדיר.

**כדאי להגן על הכתובת בסיסמה.** ב-Vercel: Settings → Deployment Protection → Password Protection. בלי זה, כל מי שיודע את הכתובת רואה את מספרי הכרטיסים.

## איפה הנתונים

ב-`localStorage` של הדפדפן. אין מסד נתונים ואין חשבון. מספרי הכרטיסים לא עוזבים את המכשיר, חוץ מרגע בדיקת היתרה — ואז הם עוברים דרך `/api/balance` אל המנפיק ולא נשמרים.

המחיר: אין סנכרון בין מכשירים, וניקוי הדפדפן מוחק הכול. יש כפתור **גיבוי לקובץ**.

לסנכרון בין מכשירים: החליפו את `lib/storage.ts` ב-Vercel Postgres או Upstash Redis, והוסיפו התחברות. הממשק לא צריך להשתנות — הוא מדבר רק עם `loadCards` / `saveCards`.

## בדיקת יתרה — מה באמת אפשרי

לאף מנפיק בישראל אין API ציבורי ליתרה. מה שיש זה עמוד ווב עם טופס, והמצב שונה מאוד בין מנפיקים:

| מצב | מה זה אומר | דוגמאות |
|---|---|---|
| `link` | יש עמוד בירור פתוח. האפליקציה מעתיקה את המספר ופותחת אותו. | מולטיפאס, ישראכרט, מקס, כאל, זארה, סופר-פארם, קרפור, קסטרו |
| `login` | יש בירור מקוון אבל מאחורי הזדהות. אי אפשר לאוטמט בלי החשבון. | דרים קארד, מועדון חבר |
| `offline` | אין בירור מקוון בכלל. טלפון או קופה. | תו הזהב, עזריאלי, ויקטורי, שופרסל |
| `auto` | מוגדר מנוע ב-`lib/engines` והאפליקציה בודקת לבד. | אחרי שתגדירו — ראו למטה |

ברירת המחדל היא `link`, כי היא עובדת תמיד ולא נשברת.

### להפעיל בדיקה אוטומטית אמיתית

ב-`lib/engines/index.ts` יש ארבעה מנועים ריקים. כל אחד מכסה כמה מותגים, כי מנפיקים חולקים מערכות:

- `multipass` → מולטיפאס, סופר-פארם, תו פלוס, קסטרו
- `isracard` → ישראכרט, רמי לוי, שופרסל, ויקטורי (כרטיס פיזי)
- `cal` → פייטר, כרטיס שדה
- `praxell` → פרקסל, גולף, שילב, LOVE CARD

למלא מנוע (5 דקות):

1. פתחו את עמוד בירור היתרה של המנפיק.
2. `F12` → Network → סמנו Fetch/XHR.
3. הזינו מספר כרטיס אמיתי ולחצו "בדוק יתרה".
4. על הבקשה שיצאה: Copy → **Copy as fetch**.
5. העתיקו ל-`ENGINES[<id>]` את `endpoint`, `headers` ו-`buildBody` (שמות השדות).
6. מלאו `parse` — לרוב מספיק `parseShekels(body)` שכבר כתוב.
7. שנו ב-`lib/providers.ts` את ה-`mode` של אותם מותגים ל-`"auto"`.

שווה לדעת לפני: גרידה של אתר צד שלישי עשויה לנגוד את תנאי השימוש שלו, היא נשברת כשהאתר משתנה, וחלק מהעמודים מוגנים ב-CAPTCHA או בטוקן CSRF שמחייב דפדפן אמיתי. עבור אלה נשארים ב-`link`.

## הוספת מנפיק

ערך חדש במערך `PROVIDERS` ב-`lib/providers.ts`. `mode: "offline"` ו-`balanceUrl` ריק זה ברירת מחדל תקינה.

## מבנה

```

components/CardTile.tsx   כרטיס בודד, עם פאנל הגירוד של היתרה
components/CardForm.tsx   הוספה ועריכה

lib/engines/index.ts      מנועי הבדיקה האוטומטית
lib/storage.ts            שכבת האחסון (localStorage)
```
